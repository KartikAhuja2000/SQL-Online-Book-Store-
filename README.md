# SQL-Online-Book-Store Database Project

**Overview**
Welcome to my Online Book Store Database project! This repository contains the SQL scripts and datasets used to build and analyze a comprehensive database for an online bookstore. The project showcases my skills in SQL, data management, and data analysis.

**Project Details**
In this project, I utilized three main datasets:

- Books: A collection of over 500 books with attributes such as title, author, genre, published year, price, and stock.
- Customers: Information on 500+ customers from various cities and countries, including their contact details.
- Orders: Records of 500+ orders detailing customer purchases, quantities, order dates, and total amounts.

**Key Features**
- Database Structure: Created relational tables for Books, Customers, and Orders with appropriate keys and relationships.
- Data Loading: Efficiently loaded large CSV datasets into the database.
- SQL Queries: Developed various SQL queries to extract insights, including:

a) Total books sold by genre and author.
b) Average price of books in the Fantasy genre.
c) Customers who placed multiple orders.
d) Total revenue generated from all orders.
e) Stock analysis to determine remaining quantities after fulfilling orders.

**Insights**
- The most expensive book is priced at $49.96.
- The Fantasy genre has an average book price of around $28.
- Identified top customers based on spending and frequently ordered books.
